## 3. Структуры данных

В `read_files` создаются **6 структур** для агрегации.

### 3.1. `calls_per_day`
**Тип:** `dict`  
**Ключ:** `datetime` (дата)  
**Значение:** `int` (число вызовов)

**Что хранит:** число вызовов для каждого дня периода.  
**Что считается вызовом:** услуги с кодами `B03.044.001.1` (взрослый) и `B03.044.001.2` (детский).

**Пример:**
```python
{
    datetime(2025, 1, 1): 2,
    datetime(2025, 1, 2): 0,
    datetime(2025, 1, 3): 4,
    ...
}
```

---

### 3.2. `calls_per_month`
**Тип:** `dict`  
**Ключ:** `tuple` `(год, месяц)`  
**Значение:** `int` (число вызовов)

**Что хранит:** число вызовов для каждого месяца.  

**Пример:**

    (2025, 1): 45,

### 3.3. `revenue_per_month`
**Тип:** `dict`  
**Ключ:** `tuple` `(год, месяц)`  
**Значение:** `float` (сумма в рублях)

**Что хранит:** выручку за каждый месяц.  
**Что суммируется:** **все** строки реестра (включая дополнительные услуги).

**Пример:**

### 3.4. `service_counts`
**Тип:** `Counter`  
**Ключ:** `str` (код услуги)  
**Значение:** `float` (объём услуг)

**Что хранит:** суммарный объём по каждому коду услуги.  
**Что считается:** `quantity` (с учётом количества).

**Пример:**
```python
Counter({
    'B03.044.001.1': 979,
    'B03.044.001.2': 171,
    ...
})
```

---

### 3.5. `diagnosis_counts`
**Тип:** `Counter`  
**Ключ:** `str` (код МКБ, первые 3 символа)  
**Значение:** `int` (число случаев)

**Что хранит:** частоты диагнозов (сгруппированы по 3 символам).  
**Что считается:** только **вызовы** (`.1`, `.2`) — у них есть диагноз.

**Пример:**
```python
Counter({
    'J06': 271,
    'I10': 144,
    ...
})
```

#### 3.5.1. Логика подсчёта диагнозов

Диагноз есть только у вызовов — услуг с кодами 
`B03.044.001.1` (взрослый) и `B03.044.001.2` (детский).

Дополнительные услуги (`.3`, `.5`, `.15`, `.18` и др.) 
диагноза не имеют — это сопутствующие процедуры.

**Логика подсчёта:**

- Вызовы — с учётом `quantity` (число вызовов).
- Диагнозы — по строкам (одно обращение = один диагноз).

`quantity > 1` в строке вызова возможна только при повторном 
выезде к тому же пациенту в тот же день после отказа от госпитализации, при этом диагноз остается тем же.
`+= quantity` дублирует диагноз при повторных выездах, что искажает заболеваемость.
